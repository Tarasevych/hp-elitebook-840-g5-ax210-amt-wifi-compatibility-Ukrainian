# Обмеження WPA2-Personal/PSK в AMT 11.8

Дата: 2026-07-09

## Спостереження

З Intel 8265 платформа показує WLAN у ME/AMT, але спроба створити WPA2-Personal/PSK профіль не пройшла.

## Значення для дослідження

| Рівень | Стан |
| --- | --- |
| Видимість обладнання | Пройдено з 8265 |
| Домашній WPA2-Personal/PSK-профіль | Не пройдено |
| AX210 видимість обладнання | Не пройдено |

## Практичний висновок

Повернення до 8265 не є автоматичним рішенням початкової Wi-Fi-only мети. Воно корисне як контрольний доказ, але для практичного BIOS / до запуску ОС / у вимкненому стані доступу все одно надійнішим лишається IP-KVM маршрут.
