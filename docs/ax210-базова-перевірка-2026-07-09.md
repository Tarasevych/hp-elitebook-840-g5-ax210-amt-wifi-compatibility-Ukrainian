# Базова перевірка AX210

Дата: 2026-07-09

## Мета

Зафіксувати, що Intel AX210 працює на рівні Windows, але не експонується як AMT/OOB WLAN на рівні ME/AMT.

## Результат

| Поле | Значення |
| --- | --- |
| WLAN | Intel Wi-Fi 6E AX210 160MHz |
| PCI ID | `VEN_8086&DEV_2725` |
| драйвер Windows | 24.50.0.4 |
| Windows Wi-Fi | Працює |
| WLAN-обладнання ME/AMT | Не показано як встановлений Intel WLAN |
| Ціль WLAN у прошивці ME/AMT | `0x24FD` / клас Intel 8265 |

## Висновок

AX210 проходить рівень ОС, але не проходить перевірку видимості для керованості в прошивці в цьому кейсі.
