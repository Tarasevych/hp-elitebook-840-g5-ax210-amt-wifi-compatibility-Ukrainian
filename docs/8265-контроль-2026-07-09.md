# Контроль Intel 8265

Дата: 2026-07-09

## Мета

Перевірити, чи HP EliteBook 840 G5 / Q78 / CSME 11.8 взагалі здатний відкривати підтримуваний WLAN-модуль у Intel ME/AMT.

## Результат

| Поле | Значення |
| --- | --- |
| WLAN | Intel Dual Band Wireless-AC 8265 |
| PCI ID | `DEV_24FD` |
| драйвер Windows | 20.70.32.1 |
| Windows Wi-Fi | Працює |
| ME/AMT ідентифікатор бездротового обладнання | `0x24FD` |
| Позначення ME/AMT WLAN | Intel Dual Band Wireless-AC 8265 |

## Висновок

8265 є позитивним контролем: платформа може бачити підтримуваний WLAN у ME/AMT. Це робить AX210-негативний результат сильнішим, бо проблема не виглядає як загальна відсутність WLAN у AMT.
