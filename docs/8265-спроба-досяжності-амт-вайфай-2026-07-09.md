# Спроба AMT Wi-Fi reachability з 8265

Дата: 2026-07-09

## Мета

Після встановлення 8265 перевірити, чи можна перейти від видимості WLAN у ME/AMT до практичного AMT Wi-Fi профілю.

## Результат

| Крок | Результат |
| --- | --- |
| Локальні AMT-запити з автентифікацією | Проходять |
| Перелік AMT network/features/power | Отримується |
| WLAN видимість обладнання | 8265 видимий |
| WPA2-Personal/PSK створення профілю | Не пройшов |

## Висновок

8265 відкриває видимий для прошивки WLAN-рівень, але не доводить повний AMT Wi-Fi у домашній WPA2-Personal мережі.
