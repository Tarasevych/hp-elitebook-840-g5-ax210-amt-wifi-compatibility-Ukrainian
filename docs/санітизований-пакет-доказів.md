# Санітизований пакет доказів

Публічний пакет доказів має бути корисним і безпечним для поширення.

## Дозволені публічні дані

| Тип даних | Приклад |
| --- | --- |
| Модель пристрою | HP EliteBook 840 G5 |
| Сімейство/версія BIOS | HP Q78 Ver. 01.31.00 |
| Версія ME/CSME | Intel CSME 11.8.97.4739 LP |
| Модель WLAN | Intel AX210 або Intel 8265 |
| PCI ID | `VEN_8086&DEV_2725`, `DEV_24FD` |
| WLAN-ціль AMT | `0x24FD` |
| Висновок | AX210 не експонується як AMT WLAN |

## Дані, які не потрібні для доказу

| Тип | Причина |
| --- | --- |
| Паролі й Wi-Fi ключі | Не впливають на доказ видимості в прошивці |
| Приватні IP | Не потрібні для відтворення сумісності |
| MAC-адреси | Ідентифікують конкретний пристрій |
| Серійні номери | Ідентифікують власника/пристрій |
| Ключі відновлення | Не мають відношення до сумісності WLAN |
| Повні дампи прошивки | Не потрібні для цієї публічної статті |
