## Рейтинг варіантів

| Варіант | Контроль Windows | Контроль BIOS / до запуску ОС | Контроль вимкненого стану | Залежність від AX210 у ME/AMT | Ризик |
| --- | --- | --- | --- | --- | --- |
| AX210 + Tailscale/RDP | Так | Ні | Ні | Немає | Низький |
| AX210 + штатний AMT Wi-Fi | Немає підтвердження | Теоретично так | Теоретично так | Повна | Невизначений |
| 8265 + AMT Wi-Fi | Частково підтверджено | Не доведено для домашнього PSK | Не доведено для домашнього PSK | Немає AX210 | Середній |
| Дротова мережа Ethernet / док-станція AMT | Так для дротового AMT | Так, якщо AMT налаштовано | Так, якщо платформа підтримує | Немає | Низький/середній |
| IP-KVM + керування живленням | Так через RDP для ОС | Так | Так, якщо умову керування живленням виконано | Немає | Низький/середній |

## Висновок матриці

AX210 має сенс залишати як сучасний Wi-Fi для ОС. Для BIOS / до запуску ОС / у вимкненому стані контролю найменше залежний від матриці прошивки шлях - зовнішній IP-KVM з приватним доступом і керуванням живленням.
