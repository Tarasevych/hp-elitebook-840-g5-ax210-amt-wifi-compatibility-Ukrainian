# Запит до HP / Intel

## Коротко

Власник HP EliteBook 840 G5 замінив WLAN-модуль на Intel AX210. Windows підтримує AX210, але Intel ME/AMT на HP Q78 / CSME 11.8 не експонує AX210 як out-of-band WLAN. Контрольний Intel 8265 на тій самій машині експонується як ідентифікатор бездротового обладнання `0x24FD`, тобто платформа може бачити підтримуваний WLAN на рівні ME/AMT.

## Просимо підтвердити

1. Чи підтримує HP EliteBook 840 G5 / Q78 / CSME 11.8 Intel AX210 як AMT/OOB WLAN?
2. Якщо підтримує, яке офіційне підписане оновлення або який шлях налаштування потрібно використати?
3. Якщо не підтримує, чи може HP/Intel опублікувати явне обмеження сумісності?
4. Які WLAN-модулі мають підтримку AMT/OOB Wi-Fi саме для цієї платформи?
5. Які типи бездротових профілів підтримує AMT 11.8 для WLAN класу 8265/8260, включно з WPA2-Personal/PSK або 802.1X/EAP-TLS?

## Чому це важливо

| Проблема | Наслідок для користувача |
| --- | --- |
| WLAN на рівні ОС і AMT WLAN не документуються окремо | Користувач купує модуль, який працює в ОС, але не закриває OOB-керованість |
| Сумісність прошивки невидима до покупки | Оновлення виглядає успішним, доки не потрібен BIOS/pre-OS/off-state доступ |
| Відсутність офіційної відповіді | Ремонтна спільнота змушена збирати непрямі докази |
| Немає чіткої матриці підтримки | IT-адміністратори ризикують ламати керованість під час масового оновлення парку пристроїв |

## Бажаний виробничий результат

| Варіант | Цінність |
| --- | --- |
| Офіційне підписане оновлення для AX210 AMT/OOB WLAN | Дає нативне рішення |
| Офіційна заява про несумісність | Дає чесну межу планування |
| Окрема таблиця "WLAN на рівні ОС" і "AMT/OOB WLAN" | Зменшує помилки апгрейду |
| Документація типів бездротових профілів AMT 11.8 | Дозволяє коректно тестувати 8265/8260 |
