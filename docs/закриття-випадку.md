# Закриття випадку

## Підсумок

Початкова мета була практичною: отримати повний віддалений доступ до власного HP EliteBook 840 G5 через Wi-Fi, включно з Windows, BIOS/pre-OS і станом вимкненого ПК.

Після дослідження мету розділено за шарами:

| Рівень | Результат |
| --- | --- |
| Windows через AX210 | Працює |
| RDP через приватний VPN | Практично придатний маршрут |
| AX210 як AMT/OOB WLAN | Не підтверджено |
| 8265 як WLAN, видимий для AMT | Підтверджено на рівні видимості обладнання |
| Домашній WPA2-Personal AMT Wi-Fi | Не доведено |
| BIOS/pre-OS/off-state | Практичний маршрут: IP-KVM + керування живленням |

## Логічне закриття

Проєкт не завершується "нічого не вийшло". Він завершується точнішим результатом:

1. AX210 є вдалим Wi-Fi на рівні ОС апгрейдом.
2. AX210 не є підтвердженим AMT/OOB WLAN для HP Q78 / CSME 11.8.
3. Intel 8265 підтверджує, що платформа може експонувати підтримуваний WLAN у ME/AMT.
4. Повний домашній AMT Wi-Fi через WPA2-Personal/PSK не доведений навіть з 8265.
5. Практичний контроль над ПК досягається через розділення: VPN/RDP для Windows, IP-KVM для BIOS/pre-OS/off-state.

## Остаточний статус

```text
Нативний AMT Wi-Fi через AX210: не доведено локальними доказами
Windows Wi-Fi через AX210: працює
Підтримуваний маршрут власника: VPN/RDP + зовнішній IP-KVM + керування живленням
```
