# План збору доказів власником

## Мінімальний набір

| Доказ | Навіщо |
| --- | --- |
| Знімок екрана Диспетчера пристроїв Windows / PnP з AX210 | Підтвердити модуль, видимий на рівні ОС |
| Версія драйвера AX210 | Відділити проблему від старого драйвера |
| Стан WLAN-обладнання ME/AMT з AX210 | Підтвердити негативний позасмуговий результат |
| Стан WLAN-обладнання ME/AMT з 8265 | Підтвердити позитивний контроль |
| Результат бездротового AMT-профілю | Відділити видимість обладнання від підтримки профілю |
| Фото IP-KVM під'єднання без приватних даних | Показати практичний обхідний практичний маршрут |

## Очищення даних

Перед публікацією потрібно прибрати:

- SSID і Wi-Fi ключі;
- приватні IP;
- MAC-адреси;
- серійні номери;
- паролі;
- ключі відновлення;
- повні знімки пам'яті прошивки.
