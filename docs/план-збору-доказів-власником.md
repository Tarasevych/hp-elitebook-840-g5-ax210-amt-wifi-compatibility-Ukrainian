# План збору доказів власником

## Мінімальний набір

| Доказ | Навіщо |
| --- | --- |
| Скриншот Диспетчера пристроїв Windows (Device Manager) / PnP з AX210 | Підтвердити модуль, видимий на рівні ОС |
| Версія драйвера AX210 | Відділити проблему від старого драйвера |
| Статус WLAN-обладнання ME/AMT з AX210 | Підтвердити негативний OOB результат |
| Статус WLAN-обладнання ME/AMT з 8265 | Підтвердити позитивний контроль |
| Результат бездротового AMT-профілю | Відділити видимість обладнання від підтримки профілю |
| Фото IP-KVM підключення без приватних даних | Показати практичний обхідний практичний маршрут |

## Санітизація

Перед публікацією потрібно прибрати:

- SSID і Wi-Fi ключі;
- приватні IP;
- MAC-адреси;
- серійні номери;
- паролі;
- ключі відновлення;
- повні дампи прошивки.
