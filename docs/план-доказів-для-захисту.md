# План доказової бази для захисту дослідження

Цей документ формує тезу як перевірну науково-технічну роботу, а не як емоційну скаргу.

## Теза

У HP EliteBook 840 G5 з HP Q78 / Intel CSME 11.8 сумісність WLAN-модуля на рівні ОС і сумісність WLAN-модуля на рівні Intel ME/AMT є незалежними шарами. Intel AX210 працює в Windows, але локально не відображається як AMT/позасмуговий WLAN. Intel 8265 на тій самій машині відображається як WLAN у ME/AMT, що локалізує межу AX210 до шару керованості в прошивці.

## Докази

| Твердження | Доказ | Рівень сили |
| --- | --- | --- |
| AX210 працює в Windows | PCI ID + драйвер + робочий Wi-Fi | Сильний |
| AX210 не видимий ME/AMT як WLAN | Стан AMT WLAN | Сильний локальний |
| Платформа здатна бачити підтримуваний WLAN | Контроль 8265 | Сильний |
| 8265 не доводить домашній PSK AMT Wi-Fi | Помилка PSK-профілю | Сильний локальний |
| Потрібна матриця виробника | Розрив між WLAN на рівні ОС і AMT WLAN | Аргументовано |

## Що ще посилило б роботу

| Додатковий доказ | Цінність |
| --- | --- |
| Незалежне повторення на іншому HP 840 G5 | Підтвердження відтворюваності |
| Тест 8265 з корпоративним 802.1X/EAP-TLS | Перевірка підтримуваного шляху AMT-профілю |
| Офіційна відповідь HP/Intel | Закриває тлумачення виробника |
| Фото/знімки екрана очищених AMT станів | Підвищують довіру без витоку секретів |
