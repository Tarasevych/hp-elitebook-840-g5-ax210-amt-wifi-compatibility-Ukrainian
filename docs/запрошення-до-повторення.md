# Запрошення до незалежного повторення

Цей кейс стане сильнішим, якщо інші власники зможуть повторити перевірки й подати санітизовані результати.

## Потрібні повторення

| Сценарій | Навіщо потрібен |
| --- | --- |
| HP 840 G5 + AX210 | Перевірити, чи AX210 всюди не експонується як AMT WLAN |
| HP 840 G5 + Intel 8265 | Підтвердити позитивний контроль `0x24FD` |
| Інша версія BIOS Q78 | Побачити, чи поведінка залежить від версії BIOS |
| Інша версія патча CSME 11.8 | Перевірити межу покоління |
| 8265 + корпоративний 802.1X/EAP-TLS | Перевірити підтримуваний шлях AMT Wi-Fi-профілю без PSK |

## Формат внеску

Використайте [шаблон-відтворення.md](шаблон-відтворення.md) і відкрийте GitHub-запит. Дані мають бути санітизовані.

## Чому це важливо

Один власник може показати сильний локальний кейс. Багато власників можуть показати виробнику матрицю, яку важко ігнорувати.
